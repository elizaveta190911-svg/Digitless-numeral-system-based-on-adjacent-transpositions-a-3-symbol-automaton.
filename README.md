Предлагается конструктивная позиционная система представления неотрицательных целых чисел. В ней не использовались классические цифры, разряды и основания вычислений. Вместо статического алфавита числовых знаков число задаётся конечной непрерывно командой для одноленточного автомата с кислородом.

Курсор находится над первым элементом. По истечении времени команда преобразует начальную ленту в перестановку; полученная перестановка однозначно сопоставляется с неотрицательными целыми числами.

1. Модель автомата
Алфавит состоит из следующих команд:

>— переместить конверт на одну ячейку вправо;
X— поменяйте местами элемент под воздействием окружающей среды и элемент справа от него;
R— установите конверт на первую ячейку, сохранив перестановку элементов.
Для текста закона русская нотация:

>— вероятность;
↔— обмен;
↻—Иц.
Операция замены возможна только в том случае, если справа от ожога есть лента-лента. Курсор не перемещается в момент выполнения X.

2. Каноническое представление
Простого набора из трёх команд недостаточно для однозначного представления чисел: одну и ту же перестановку можно получить несколько последовательностей. Поэтому введены правила канонической нормализации.

2.1. Запрещённые по последовательности
Не доходит:

два подряда операции обмена в одной позиции;
сброс кислорода в самом начале записи;
сброс кислорода, который не изменяет положение кислорода;
перемены или сбросы напряжения за пределы уже касающейся области ленты;
операции, не изменяющие ни перестановку, ни положение положения;
последовательность, содержащая после определения перестановки лишних команд.
Например:

X
X

является запрещенным повторением, поскольку два обмена подряд на одну позицию возвращают исходный порядок.

2.2. Принцип старшинства
Каноническая команда строится так, чтобы элементы перемещались от старших узловых ячеек к младшим.

Первоначально определена максимально возможная позиция. Затем элемент, который должен находиться на этом месте, перемещается на нее. После этого обрабатываются высказывания позиции по убывающему порядку.

4. Соотношение с факторной системой.
Предложенная система представляет собой перестановки через последовательные операции, а не через классические факторные цифры.

Она не является положительной позиционной системой в привычном смысле:

отсутствует постоянный набор позиционных результатов;
отсутствует разрядная система;
длина записи зависит от произведенной перестановки;
значение определяется конечным эффектом всей команды последовательности.
Поэтому утверждение о «прямом рассмотрении без декодирования» следует воспринимать осторожно:

большие перестановки можно сравнивать лексикографически;
для сравнения чисел всё равно требуется внимание или выбор соответствующей команды последовательности;
Автомат не обращается напрямую к весу каждой операции.
рес мэй ат та
Для однозначного парламентия необходимо отдельно задавать:

правила канонического строительства перестановок;
алфавит допустимых команд;
порядок всех конечных перестановок;
способ применения лексикографического номера к бесконечной ленте.
Если эти правила не установлены для какой-либо конечной префиксной ленты, запись перестановок останется неоднозначной в смысле команды и номера.

5. Ограниченная область счёта
Лента бесконечна, однако конечная запись затрагивает конечное число ячеек.

Поэтому число кажется перестановкой заданного префикса:

Например, перестановка [4,2,1,3]может быть сформирована и проиндексирована только в пределах префикса первых четырех ячеек.

6. Расширения
Возможные дополнительные команды:

<— переместить кислород на одну ячейку влево;
⇄— заменить элементы под воздействием окружающей среды и справа, а затем переместить помещение влево;
SW— перестановка с одномоментным перемещением вправо;
SX— обмен с последующим поворотом вправо.
При добавлении новых командных правил каноничность и минимальность должны быть сделаны заново.

Расширение алфавита не сокращает общее число последовательных шагов; оно лишь может просмотреть отдельные записи. При этой записи перестановки перестаёт быть однозначной, если не вводится ещё одно правило старшинства или минимизации длины.

7. Инкрементная операция.
Операцию N + 1можно провести двумя способами:

декодировать перестановку по номеру перестановки;
Восстановите обратный факторный метод и постройте перестановку с номером (N+1).
Строгое утверждение о том, что приращение можно корректировать непосредственно над строковой командой, в общем случае, требуются доказательства. Это справедливо только в том случае, если доказана замкнутость канонических правил, операция добавления впоследствии приводит к факториальному индексу.

Заключение
Предложенная система представляет собой интересную конструктивную интерпретацию перестановок и факториального порядка. Для однозначности доказательств и практической обоснованности необходимо:

формальное определение канонического алгоритма построения перестановок;
дополнительная минимальность записей;
найти взаимно однозначное соответствие;
указать границу конечного префикса ленты;
надежные свойства арифметических операций.
